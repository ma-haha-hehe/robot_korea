# 能力范围与评测口径

本仓库提供 Workbenchmark 任务导入、Panda/MuJoCo 仿真、ROS 控制与观测接口、
参考执行器和自动评测工具。发布源码不附带逐次执行日志；运行结果由使用者保存到本地 `runs/`。

## 支持范围

| 功能 | 范围 |
|---|---|
| 零件 | 注册的 `brick_2x2`、`brick_4x2`；扩展类型需提供几何、质量和对称性 |
| 任务输入 | v1 产品 YAML、最新版三文件 Workbenchmark、旧版任务适配器 |
| 仿真 | Panda 双指夹爪，MuJoCo 刚体动力学与 ROS 2 Humble 接口 |
| 参考执行器 | 拆解逆序规划、0°/90° 抓取、受限碰撞检查、抓取/释放确认和有界恢复 |
| 观测 | Oracle 真值、RGB-D、仿真分割；可选 GroundingDINO/SAM/FoundationPose 适配器 |
| 评测 | 末态误差、真实释放与支撑、接触深度、阶段状态、时间及输入/源码指纹 |

Oracle 控制器直接读取仿真中的积木位姿和接触力，其结果只评价该条件下的规划与控制。
视觉模型、学习策略、触觉模型和实机泛化必须使用各自的观测与执行链单独评测。
可选 GPU 后端的接口实现不等于 GPU 推理或真实视觉闭环已验收。

## 三类连接配置

- `snap`：公开声明的简化扣合机制，适合接口开发和几何流程调试。
- `physics` + `loose`：空心刚体、重力与接触，无自动吸附。
- `physics` + `plastic`：柔顺内筋、过盈与摩擦扣合，无运行时焊接或积木传送。

不同配置采用不同的几何、接触和执行条件，应分开报告。塑料接触参数未经实物材料标定，
不能解释为真实 ABS 的材料参数。详见[接触模型](PLASTIC_CONTACT_ZH.md)。

## 验证层级

1. 格式验证确认输入字段、类型和单位。
2. 静态审计检查实体重叠、名义支撑、层高与抓取几何。
3. 代码测试检查模块和接口行为。
4. 完整仿真执行必须从原始初态开始，完成全部积木、释放、撤离和末态稳定性检查。
5. 实机实验还需要真实传感、标定、硬件控制与物理结果的独立验证。

前一级通过不能替代后一级。400 个任务能够导入不表示 400 次机器人执行成功；
固定布局的抽样也不能直接代表随机布局鲁棒性或全数据集成功率。

## 评测约定

塑料模式采用 XY 1 mm、Z 0.4 mm、倾斜 3°、按零件对称性计算的偏航 8°，
并检查最大数值穿透不超过 0.5 mm。参考执行器还要求实际松爪、真实支撑和最终全体唤醒后
1 秒稳定性检查。最终误差合格但执行中违反接触或释放约束的案例不能计为成功。

比较方法时需固定任务文件、初始布局、seed、观测模式、连接/接触配置、基座位置、
控制器及资源预算，并完整保存本地运行结果。超时、未执行、部分完成和成功应分别统计。
改变目标、减少块数或放宽容差后得到的结果属于另一实验条件。

运行命令见[评测指南](VALIDATION_ZH.md)，自动抽样与阶段证据见
[状态机指南](EXECUTION_STATE_MACHINE_ZH.md)。
