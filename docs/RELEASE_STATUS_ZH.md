# 版本与验证范围

本版本提供 Workbenchmark 导入、0°/90°逆向抓取规划、Oracle 机械臂执行、塑料接触模型及实际开爪确认。

## 当前控制器

位姿补偿前及每次补偿后，执行器检查双指与目标的实际承载接触。
缺少任一侧接触时，机械臂保持当前关节目标，最多等待80毫秒；未恢复则停止位姿补偿。

本地代码测试：227项通过、1项跳过。单块塑料接触任务
`final_product_blue_single`（seed=42）已完成实际抓取、放置和松爪验证。

## 已归档的多任务验证

控制器更新前的发布版本保留了36项原始 Workbenchmark 任务的完整 Oracle 物理执行证据：
seed=42，基座 X=-0.05 m，包括30项第一层级任务、2项第二层级任务和4项第三层级任务。
这些记录对应各自的源码哈希，不作为更新后控制器的新回归结果。

每项记录核对进程退出状态、逐块末态、接触穿透、坐实支撑、双指实测全开并脱离，
以及最终全体积木唤醒后的1秒稳定性。
[机器可读证据](validation/workbenchmark_plastic_20260924.json)包含实际结果、末态、动作计划、源文件哈希及计划复用依据。

验证范围以上述具体版本和任务为准。固定240项抽样清单定义回归输入，不表示全部任务已经验收。

## 接触模型与可选后端

塑料模型使用柔顺内筋和摩擦扣合，无运行时焊接或积木位姿传送。
轴向夹具中的2×2/2×4拔出力约为3.0/5.8 N，属于未做实物标定的仿真结果。

GroundingDINO/SAM/FoundationPose接口可选；真实GPU推理及实机操作未验收。
运行方法见[README](../README.md)，参数见[接触模型说明](PLASTIC_CONTACT_ZH.md)，
线上检查状态见[GitHub Actions](https://github.com/ma-haha-hehe/robot_korea/actions)。
