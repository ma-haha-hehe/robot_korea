# 塑料扣合接触候选

`mj_bridge.plastic_contact` 为自建空心积木增加内筋、管壁过盈和 2 mm 导入斜面。扣合阻力来自柔顺接触与库仑摩擦，不创建焊接约束、不固定积木位姿。

`hollow_plastic_clutch_v2` 将每段管壁、内筋和导入斜面做成一个连续凸碰撞体，消除分离碰撞体接缝处的内部端面。旧 v1 场景可以直接回放已保存的 XML；重新生成须使用新版配置。

外壳墙面和顶面使用与原盒体尺寸相同的八顶点凸网格。这里改变的是碰撞求解表示，外形、壁厚、质量和摩擦参数均保持不变。本机MuJoCo 3.11的解析盒体碰撞在某些近乎平行的旋转矩阵下会报告远大于实际间距的深接触；等尺寸凸网格通过对应数值回归。接触上限仍是0.5mm，异常读数不会被直接忽略。

当前已接入正式生成和执行入口，通过 `--connection-mode physics --contact-profile plastic` 显式启用；默认仍是原有松配合模型。参数没有实物测量标定，不能称为真实 ABS 材料模型。整体自动装配尚未验收。

| 参数 | 当前值 |
|---|---:|
| 内筋与对齐凸点的名义过盈 | 0.05 mm |
| 接触维数 `condim` | 6（含扭转与滚动摩擦） |
| 内部滑动摩擦系数 | 0.3 |
| 扭转摩擦长度 | 0.001 m |
| 滚动摩擦长度 | 0.00005 m |
| 接触时间常数 / 阻尼比 | 0.03 s / 1 |
| 接触阻抗 `solimp` | 0.9 0.95 0.001 |

这些是 MuJoCo 求解器参数，不是杨氏模量。参数含义见 [MuJoCo 接触参数说明](https://mujoco.readthedocs.io/en/stable/modeling.html#solver-parameters)。外壳硬接触及原有夹爪力限幅保持独立，不能通过增大允许穿透来接受失败插入。

夹具与机器人场景均使用 Newton 求解器、pyramidal 摩擦锥、0.5 ms 步长。椭圆与棱锥摩擦锥具有不同的柔性接触动力学；参数验证须使用相同配置，详见 [MuJoCo 接触模型](https://mujoco.readthedocs.io/en/latest/computation/)。结果报告包含实际求解器设置。

## 轴向夹具验证

```bash
source enter_sim_env.sh
export PYTHONPATH="$PWD/src/mj_bridge:$PYTHONPATH"
python scripts/check_plastic_contact.py --output runs/plastic-contact-check.json
```

夹具固定下块，限制上块的侧向与转动自由度，仅沿插入轴施加力。3 N 压入后撤力，再以 2 N/s 递增拔出力，最大 12 N。积木位置由动力学积分得到。它用于接触模型诊断，不能代替自由放置或机械臂验证。

本机v2、6维接触夹具结果：2×2 / 2×4 均完全坐实；撤力后高度误差小于 8 µm；对应拔出力为 3.0 / 5.8 N，最大内部接触形变约 0.05 mm。这些值只适用于该夹具、尺寸和求解器配置，不能当作实物测量值。

机械臂隔离候选使用最多 4 mm 的反馈插入行程，要求高度误差小于 0.4 mm、倾斜不超过 3°，随后依旧确认双指完全张开并解除目标接触。三块任务已通过这一候选检查；正式入口的三块任务已通过；较复杂任务仍在验证，不能据此认定全部 Workbenchmark 通过。

## 执行与零件导出

```bash
python -m mj_bridge.benchmark_cli run --product runs/workbenchmark-recorded/tier2_task_001.yaml --seed 42 --output-dir runs/plastic-example --connection-mode physics --contact-profile plastic --executor oracle-baseline --robot-base-x=-.05 --headless

```

塑料接触仅允许与 `physics` 配合。生成清单和执行结果记录接触配置，执行结果另记录模块及实际生成模型的 SHA256。压入最多增加 4 mm 行程，横向偏差超过 1 mm 或倾斜超过 3°时停止；坐实高度误差须小于 0.4 mm。充分张开双指并解除目标接触的撤离条件保持不变。

桌面、地面和底板实体表面使用硬支撑接触；内筋与凸点之间保持柔顺接触。这样可避免内部扣合参数不当地软化桌面支撑。夹爪力限仍为每指 5 N。

## 底板安装与放置反馈

导入器将成品整体平移到装配区，保持积木间的相对位置和角度。有些成品居中后会偏离底板凸点网格半格。塑料模式根据首层积木网格调整固定底板的安装位置，单轴最多移动 8 mm；成品目标和零件初始位置不变。偏移写入 `assembly_fixture.position_offset_xy_m`，回放时使用同一安装位置。首层不能落在同一网格上时直接报告配置错误。

最终插入对支撑面积不足 75% 的上层积木减速。Oracle 模式还在每个物理步监测宽边抓取的倾斜：积木离目标高度超过 20 mm 且倾斜超过 1° 时暂停原下降轨迹，根据实际手中位姿校正，再以不超过 2 mm 的步长下降。空中恢复仅在双指仍有夹持力、无外部接触且倾斜不超过 8° 时允许；近装配面和最终验收仍为 3°。视觉模式尚未验证手中跟踪，不能使用这项 Oracle 反馈作为视觉验收证据。

直接插入在目标上方 1 mm 处先松爪；姿态反馈下降则在实测高度差小于 1.5 mm 时释放，下降指令下限仍为目标上方 1 mm。确认双指充分张开、速度收敛且无目标接触后，机械臂抬高并闭合空夹爪，用指端顶部压合。接近高度由实际碰撞体顶面计算，再执行每步 0.25 mm、总行程最多 4 mm 的压合；避免一次移动到名义坐实高度而撞击尚未落稳的积木。

压合还检查刚性底面附近的实际承重接触：接触点距底面不超过 0.2 mm，法线近乎竖直，法向力总和大于 0.01 N。若内筋摩擦已承重、刚性底面尚无明显法向力，则要求向下底面间隙小于20µm，且来自其它积木、固定底板或地面的实测向上接触合力达到自重的80%以上；夹爪力不计入。两类支撑证据分别记录，不能单凭名义高度判定坐实。夹指接触、侧向接触和内部柔顺筋条不计入底部支撑。高度误差须小于 0.4 mm；部分支撑还要求倾斜小于 0.2°、横向偏差小于 0.1 mm，充分支撑使用统一的 3°、1 mm 验收上限。

待取料区的静止积木可以休眠。Oracle 在开始抓取每块积木前，将该动态树设为不休眠，并通过正常物理步确认已唤醒；直到松爪和撤离完成，持续求解目标接触。已释放积木通过逐块末态检查后恢复正常休眠政策。下一次进入装配区前，先主动唤醒全部已装配支撑，完成物理步后再接近。最终将所有积木设为不休眠，继续积分1秒后复核整体末态，并保存逐块接触可观测记录。上述操作不修改积木位姿或施加虚构唤醒力。松爪确认同时要求目标接触可观测，报告缺少该证据时不能计为通过。MuJoCo 会省略休眠物体的部分接触，因此旧版本的空接触列表不能单独证明已经脱离夹爪或缺少底部支撑。

压合完成后，先让关节控制目标保持在实测姿态，消除持续下压的指令超程，再充分张开夹爪。双指位置、速度和目标接触检查全部通过后才执行抬升；开爪超时仍停止任务。

塑料模式的运行评分和逐块检查均使用 1 mm 横向、0.4 mm 高度、3°倾斜上限，缺少实际姿态不能判为成功。普通松配合模式的评分保持原规则。

桌面接触保留 1 µm 的碰撞检测边距，以避免共面凸碰撞体在本机求解器中出现错误的深接触。该边距不改变零件尺寸、目标位置或允许穿透上限。

## 松爪后顶压

宽边抓取发生姿态漂移后，先在空中校正。姿态反馈下降在距离目标不足1.5mm时可充分松爪，使夹持力不再阻碍凸点进入凹槽，再抬升60mm、闭合空爪、从顶部压合。普通插入若在4mm附加行程内仍未坐实，只允许在积木已进入最后4mm、横向误差小于1mm且倾斜小于3°时尝试一次同样的动作。压合后仍须满足原来的0.4mm坐实和0.5mm接触限值；失败不会无限重试。

少数密集成品没有直接0/90度全开夹爪放置顺序。`plan_with_release_above` 先保留原直接拆解逆序规划，仅在抓取通道受阻时尝试提高侧壁抓取位置6mm，在目标上方10mm松爪，再顶部压合。几何规划按工具总抬高16mm检查夹爪通道。该模式单独标为 `release_above_press`，不宣称是可逆的直接拆解抓取。原始目标不改，非法重叠仍拒绝。普通成品的直接计划保持原样。

两种动作都必须先测得双指各张开至少39.5mm、速度低于2mm/s、与目标的接触间距大于0.1mm，连续保持80ms，才允许抬升。开爪超时直接失败。顶部压合根据实际指尖碰撞体边界计算接近高度，不传送或焊接零件。这些动作目前仅用于Oracle物理模式。

6维接触增加求解约束数量；场景预留128MiB求解内存。默认配置的单轮墙钟上限为600秒；塑料密集任务可通过 `MJ_BRIDGE_BENCHMARK_CONFIG` 指定 `examples/config/plastic_benchmark.yaml`，使用3600秒计算预算。新预算仅用于新运行，不改变物理步长、力、接触和坐实验收阈值；实际预算记录在结果的 `wall_clock_limit_s`。这是资源上限，不代表运行速度承诺。不同接触模型及控制器版本的执行记录分别保留。

规划只能在直接拆解顺序受阻时选择上方释放。候选排序将每层轮廓交叠比例沿下层支撑链累积，再比较面积。紧邻下层完全覆盖上层积木，但下层本身悬挑时，不能视为完整底座支撑；该策略用于减少自由落位冲击。对不超过12块的成品，若贪心计划需要在底面未完整支撑处高位松手，再搜索可达的拆解状态，优先减少这类落位，再比较高位松手次数和支撑链评分。没有改善时保留原计划。该排序是几何策略，仍必须通过执行中的接触、松爪和末态检查。

验证报告允许有条件复用直接计划：只在旧、新规划器的直接返回路径及其余模块、模型和配置完全一致，且记录的直接计划与最终规划器输出一致时接受。必须提供旧规划器源码和原始哈希；运行过上方释放分支的结果需要重新验证。原始执行哈希不被覆盖。

对于不超过12块的成品，直接规划在可安全拆解的状态中搜索，优先减少2×4长边夹持次数；全部已为窄边抓取时保留原顺序，无法降低宽边次数时也保留原顺序。更大成品保留原有有界贪心规划，避免指数搜索拖慢任务。角度仍仅0/90度，不能通过忽略邻块碰撞来获得窄边抓取。

仅离散规划函数变化时，报告另支持 `--reuse-equivalent-plans`：必须提供原规划器源码及原哈希，旧/新规划器根据原始目标重算的每一步都与实际记录完全相同，并且抓取几何与角度转换代码、所有控制器、接触模型和配置均不变，才允许复用。任何顺序、角度或动作模式变化都需要重新运行。重算计划相同不代表新计划已通过物理测试。

## 空中姿态恢复与结果复用

宽边夹持的积木有时会在减速时出现短暂滚动。空中反馈允许在以下条件全部满足时保持当前测得高度、纠正姿态：积木高于目标20mm以上，倾斜不超过8°，左右指尖各有大于0.01N的实际法向接触力，积木没有接触夹爪以外的物体。丢失任一指接触、接触其他物体或超过范围都会停止。只有倾斜小于0.3°且横向误差小于0.1mm才继续分步下降；接近装配面及最终坐实的3°要求保持不变。这是受约束的空中恢复，8°不是放置验收阈值。

只有这段空中反馈代码变化时，未进入该段反馈的完整成功结果可以单独核对复用。报告要求旧执行器源码及原哈希，确认其余执行器代码完全相同，并检查成功返回必写的pose_feedback标记。记录中出现该标记的任务必须重跑；缺失完整坐实或松爪记录同样拒绝复用。该检查还要与其他模块、模型、配置及最终动作顺序的核对同时通过。
