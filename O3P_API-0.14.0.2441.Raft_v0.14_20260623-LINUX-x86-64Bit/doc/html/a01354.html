◆ setCameraParameters()

O3P_API void setCameraParameters ( unsigned  fps,
bool  hdr,
const std::string &  range,
unsigned  distanceOffset = 0 
)

Set all camera use case parameters of the device at the same time (avoiding possible intermediate invalid states).

Note that not all combinations of settings may be valid, depending on the device capabilities. In case of an invalid combination, an exception is thrown and no settings are changed.

Exceptions
std::runtime_errorif the pipeline is not initialized or the parameter combination is rejected by firmware
