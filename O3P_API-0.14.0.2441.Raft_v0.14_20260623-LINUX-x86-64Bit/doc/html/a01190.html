O3P_API bool collectCrashLogs ( std::function< void(const char *log)>  logCallback)

Collects crash logs from the device.

The provided callback will be called for each crash log message received. This function will block until all crash logs have been collected.

Parameters
logCallbackCallback function to receive crash log messages. The log message is provided as a null-terminated C string.
Returns
True if crash log collection was successfully started, false if it was already running or if there was an error starting crash log collection.

◆ startCollecting()

O3P_API bool startCollecting ( std::function< void(const char *log)>  logCallback,
uint32_t  pollIntervalMs = 100 
)

Starts collecting live firmware logs from the device.

The provided callback will be called for each log message received. This is an asynchronous function call that returns immediately. Logs will be received in the callback until stopCollecting is called.

Parameters
logCallbackCallback function to receive log messages. The log message is provided as a null-terminated C string.
pollIntervalMsInterval in milliseconds at which to poll the device for new logs. Default is 100ms. Setting this too low may cause increased CPU usage.
Returns
True if log collection was successfully started, false if it was already running or if there was an error starting log collection.

◆ stopCollecting()

O3P_API void stopCollecting ( )

Stops collecting live firmware logs from the device.

After calling this function, the log callback provided to startCollecting will no longer be called.
