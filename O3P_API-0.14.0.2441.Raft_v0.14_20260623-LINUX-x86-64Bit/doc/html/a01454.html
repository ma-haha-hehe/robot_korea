Detailed Description

V4L2 UVC device helper with asynchronous frame capture.

A background thread continuously dequeues frames from the V4L2 driver and copies the latest one into an internal buffer. readSample() blocks until a new frame is available, matching the DSHelper/DirectShow behaviour.
